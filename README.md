# Talleres Enrique

Carpeta de trabajo organizada por finalidad:

- `talleres-enrique/`: sitio web público.
- `talleres-admin/`: aplicación de administración.
- `DOCUMENTACIÓN/01_Cuestionarios/`: recopilación de contenidos del cliente.
- `DOCUMENTACIÓN/02_Presupuestos/`: presupuestos en formato editable y PDF.
- `DOCUMENTACIÓN/03_Revisión_web/`: informes, capturas y material de control de calidad.
- `DOCUMENTACIÓN/04_Técnica/`: documentación técnica del proyecto.
- `ASSETS/`: recursos gráficos originales compartidos.
- `HERRAMIENTAS/`: scripts auxiliares de captura, generación y exportación.

Responsable principal: Javier Fernández Gutiérrez. La aplicación Android no forma parte del alcance aprobado y la fecha objetivo de lanzamiento está por definir.

Las carpetas `node_modules/` y `dist/` son generadas por las herramientas de desarrollo y no deben tratarse como fuentes originales.
